Docker in 15 minuti: il tuo primo container

Niente teoria infinita: installiamo Docker, avviamo un web server con un solo comando e costruiamo la nostra prima immagine.

Rosario Marra28 ottobre 2026 · 6 min di lettura

Immagine e container: l'unica teoria che serve

Un'immagine è un pacchetto pronto all'uso: contiene un'applicazione e tutto ciò che le serve per funzionare. Un container è un'immagine in esecuzione. Dalla stessa immagine puoi avviare tutti i container che vuoi, come da una ricetta puoi preparare più piatti uguali.

1. Installa Docker

  • Windows e macOS: scarica e installa Docker Desktop, poi avvialo.
  • Linux: installa Docker Engine seguendo la guida ufficiale per la tua distribuzione.

Apri un terminale e controlla che tutto funzioni:

docker --version
docker run hello-world

Se compare il messaggio "Hello from Docker!", sei pronto.

2. Avvia un web server con un comando

docker run -d -p 8080:80 --name web nginx
  • -d avvia il container in background;
  • -p 8080:80 collega la porta 8080 del tuo computer alla porta 80 del container;
  • --name web dà un nome al container;
  • nginx è l'immagine, che Docker scarica da Docker Hub se non ce l'hai.

Apri il browser su http://localhost:8080: vedrai la pagina di benvenuto di Nginx.

3. I comandi che userai ogni giorno

ComandoA cosa serve
docker psElenca i container in esecuzione (-a anche quelli fermi)
docker logs webMostra l'output del container
docker stop webFerma il container
docker rm webElimina il container
docker imagesElenca le immagini scaricate

4. La tua prima immagine con un Dockerfile

Crea una cartella con un file index.html qualsiasi e, accanto, un file chiamato Dockerfile:

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html

La prima riga parte da un'immagine Nginx leggera, la seconda copia la tua pagina al posto di quella predefinita. Ora costruisci e avvia:

docker build -t mio-sito .
docker run -d -p 8080:80 --name mio-sito mio-sito

Se la porta 8080 è già occupata dal container di prima, fermalo con docker stop web oppure usa un'altra porta, ad esempio -p 8081:80.

Su http://localhost:8080 ora c'è la tua pagina, servita da un container che puoi avviare identico su qualsiasi computer con Docker.

Prossimi passi

Da qui si passa a volumi, reti tra container e Docker Compose per gestire applicazioni con più servizi, come un'API con il suo database.
