Analisi dati con Python e Pandas: da dove iniziare

Un file CSV, una decina di righe di Python e hai già risposto a domande vere sui tuoi dati. Vediamo il flusso completo con un esempio semplice: i voti di una classe.

Rosario Marra14 ottobre 2026 · 6 min di lettura

1. Installa le librerie

pip install pandas matplotlib

Lavoriamo su un file voti.csv con tre colonne:

studente,materia,voto
Anna,Informatica,8
Luca,Informatica,5.5
Anna,Sistemi e Reti,7
Luca,Sistemi e Reti,
Marco,TPSIT,6.5

Nota il voto mancante di Luca in Sistemi e Reti: nei dati reali capita sempre.

2. Carica ed esplora i dati

import pandas as pd

df = pd.read_csv("voti.csv")
print(df.head())      # prime righe
df.info()             # colonne, tipi e valori mancanti
print(df.describe())  # media, minimo, massimo...

Un DataFrame è una tabella: righe e colonne con un nome. info() è il primo comando da lanciare, perché ti dice subito quante celle sono vuote.

3. Pulisci i dati

df = df.dropna(subset=["voto"])      # elimina le righe senza voto
df["materia"] = df["materia"].str.strip()

In alternativa a dropna puoi riempire i vuoti con fillna(). La scelta dipende dalla domanda a cui vuoi rispondere: inventare un voto, di solito, non è una buona idea.

4. Fai domande ai dati

# Chi ha un voto insufficiente?
insufficienti = df[df["voto"] < 6]
print(insufficienti)

# Media per materia, dalla più bassa alla più alta
media = df.groupby("materia")["voto"].mean().sort_values()
print(media)

Il filtro con le parentesi quadre e groupby sono i due strumenti che userai più spesso: il primo seleziona righe, il secondo riassume gruppi.

5. Il primo grafico

import matplotlib.pyplot as plt

media.plot(kind="barh", title="Media voti per materia")
plt.xlabel("Voto medio")
plt.tight_layout()
plt.show()

Con kind="barh" ottieni barre orizzontali, più leggibili quando i nomi delle categorie sono lunghi.

Riepilogo

  • read_csv per caricare, info e describe per capire i dati;
  • dropna / fillna per gestire i valori mancanti;
  • filtri e groupby per rispondere alle domande;
  • .plot() per trasformare il risultato in un grafico.
