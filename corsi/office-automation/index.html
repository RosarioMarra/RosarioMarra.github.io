Come si lavora

Dal file alla consegna.

Lo stesso metodo per tutti i 32 esercizi, in Excel o in Google Fogli.

Scarica il file

Ogni esercizio è un file .xlsx. Per Google Fogli: caricalo su Drive e scegli «Apri con › Fogli Google».

Leggi la Guida funzioni

Il primo foglio spiega sintassi ed esempi funzionanti di tutte le funzioni che ti servono.

Compila le celle gialle

Il foglio «Istruzioni» dice cosa calcolare: le celle da completare sono evidenziate in giallo.

Consegna su Classroom

Rinomina il file come Cognome_Nome_1_1.xlsx (lezione_esercizio) e consegnalo nel compito.

Tutto il corso in un unico file

Le 3 presentazioni e i 32 esercizi divisi per lezione, con un file LEGGIMI.
